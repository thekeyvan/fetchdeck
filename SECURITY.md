# Security Policy

## Supported version

Security fixes are applied to the latest FetchDeck release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability involving arbitrary code
execution, credential exposure, unsafe file writes, or signature verification.
Use GitHub's private vulnerability reporting feature for this repository.

Include:

- the affected FetchDeck version;
- the macOS version and processor architecture;
- reproduction steps;
- expected and observed behavior; and
- a minimal proof of concept that contains no real credentials or private
  media.

Never include browser cookies, a `cookies.txt` file, Apple credentials, or
downloaded private content.
